TalentFit · Windows 本地便携版

1. 将整个文件夹解压到可写目录，双击 TalentFit.exe。
2. 第一次打开「模型设置」，填写接口地址、模型和 API Key，保存并测试连接。
3. 新建岗位并粘贴 JD，然后一次选择或拖入多份 PDF、DOCX、TXT 简历。
4. 解析及评分自动执行。失败任务可以单独重试；评分重试会复用候选人。
5. 勾选同岗位 2–4 位已匹配候选人，点击横向比较。可以导出 CSV。

无需安装 Node.js、Python 或 npm。支持 Windows 10 / 11 x64，使用本机 Edge / Chrome 显示独立窗口；找不到时打开默认浏览器。
AI 分析需要网络和可用的模型服务。未配置模型时仍可打开界面、浏览已有结果。
文本 PDF、DOCX、UTF-8 / UTF-16LE / GB18030 TXT 均可上传，每份不超过 10 MB。
图片型 / 扫描 PDF 需要先 OCR 转成文字；旧版 .doc 请先另存为 .docx。

处理时请保持窗口打开。应用内切换页面不会停止队列；刷新或退出后，已保存的候选人和报告仍在，未完成评分可从候选人列表重新开始。
同岗位相同简历正文会复用候选人，避免重复创建。评分失败保留先前已完整保存的报告。
关闭窗口后，服务留在系统托盘。右键托盘图标选择「退出 TalentFit」可停止后台服务。
再次双击会打开已有服务，不会启动第二套后台。端口冲突时自动尝试其他本机端口。

数据：data/talentfit.db。包含简历、报告和模型配置，备份前先退出程序，再复制整个 data 文件夹。
更新：退出程序后替换 app、python、dist 和 TalentFit.exe，保留 data 文件夹。
排错：查看 logs/server.log。不要删除 python 或拆分文件夹中的文件。
分发：使用 release/TalentFit-Windows-x64.zip；日常使用后的 data 和 logs 包含本机业务内容，不要随包分发。

达标率按各维度 min(当前等级 / 岗位目标, 1) 加权计算。超出目标的优势单独展示；低置信度与软性维度需面试核实。
所有分析仅用于辅助比较及准备面试，最终判断由招聘人员作出。
